#0 今の draft5

薄グレーの角丸 24px 箱 + 両端揃えの番号行 + 右下の黒丸矢印

生成 UI に共通する 3 点セット(角丸の淡色カード / 「01 … LABEL」の両端揃え / 黒丸の矢印ボタン)がそろっている。さらに直上の事業カードと同じ「番号 + 英語ラベル」の型を繰り返しているので量産感が出る。3 枚が完全に同型・同文字量で、固有の情報(数字・固有名詞)がないのも「どの会社にも貼れる文」に見える一因。

#A おすすめ · 編集リスト

箱をやめて、目次のような 3 行にする

日本のコーポレートサイトの「募集職種一覧」の型。英語ラベル・大きな日本語見出し・説明・テキストリンクを横一列に置く。角丸も丸矢印も番号もなし。行全体がリンクで、ホバーで見出しが青くなる。横幅を自然に使い切るので密度の問題も消え、直上の写真カードとの対比で「切り替わった」感じが出る。矢印は下の応募ボタンの 1 つだけになる。

#B 罫線だけの 3 カラム

3 列は保つが、箱・角丸・丸矢印を全部外す

各列の上に太い罫線を 1 本引くだけ。印刷物(会社案内のパンフレット)の組み方に近く、余白で見せる。カードの「枠」がなくなるので生成 UI の印象が薄れる。リンクは下線付きの文字だけ。3 列の型を残したいときの案。

#C 最小限のカード

箱は残すが、装飾を削る(白地・1px・角丸 6px・番号なし・丸矢印なし)

「箱そのもの」が問題なのか、「装飾(角丸 24px・淡色地・番号行・丸矢印)」が問題なのかを切り分けるための案。箱を最小限にすると帳票のような落ち着きが出るが、#0 との差が小さく感じるならカード型自体を捨てて #A/#B に行くべき。
